## Table B - Role engine deep dive (the 35% axis)

| Game | Roles available | Selection | Resolution | Follow? | Can roles be lost/killed? |
|------|-----------------|-----------|------------|---------|---------------------------|
| **Citadels** | 8-9 numbered | Secret, one each, some discarded | Strictly by number | No | Yes - Assassin kills a role |
| **Libertalia** | Identical hand of ~9/day | Secret, simultaneous reveal | By rank, high first | No | Cards are spent, some steal/kill |
| **Witch's Brew** | Numbered role cards | Secret, simultaneous | Ascending order | No | Some roles nullified |
| **Mission: Red Planet** | 9 numbered | Secret, one each | By number | No | Roles can be blocked |
| **Broom Service** | Role cards in hand | Played openly, brave/cowardly | Immediate | No | Cowardly fails if contested |
| **San Juan** | 5 roles | Open, rotating | Immediate | Yes, all may follow | No |
| **Puerto Rico** | 7 roles | Open, rotating | Immediate | Yes, with cost | No |
| **Race for the Galaxy** | 5 phases | Secret simultaneous | All chosen phases fire | Yes, automatically | No |
| **Glory to Rome / Uchronia** | 6 roles | Open lead | Immediate | Yes, with bonus | No |
| **Love Letter** | 8 numbered | 1 card held | Compare on play | No | Yes, eliminated each round |
| **Coup** | 5 character cards | Bluff any role | Claim + challenge | No | Yes, lose influence |
| **Mascarade** | ~6 roles | Shuffled, hidden even from you | On reveal | No | Swap/steal |
| **Bang!** | 4 roles + characters | Dealt, hidden | Continuous | No | Yes, eliminated |

**Takeaway:** only **Citadels, Libertalia, Witch's Brew, Mission: Red Planet and Love Letter** combine
*secret numbered selection* with *order-based resolution*. Everything else is either open
(Puerto Rico, San Juan, Glory to Rome) or simultaneous-without-order (Race for the Galaxy).

## Table D - Scoring compared

| Game | How you score | End trigger | Catch-up / denial |
|------|---------------|-------------|-------------------|
| Citadels | District costs + 3 per colour set + 4 first / 2 later finishers | First to 8 districts (7 at 2-3p) | Assassin, Thief, Warlord destroy districts |
| Libertalia | Loot value + set bonuses per day | 3 voyages / 3 days | Steal, kill, and deny crew |
| Glory to Rome / Uchronia | Influence from buildings in your tableau | Deck exhaustion / pool empty | Legionary raids, patron tricks |
| San Juan | Building values + bonus tiles | 12 buildings | Little direct denial |
| Race for the Galaxy | VP chips + tableau VP | VP pool or 12 cards | Almost none |
| Puerto Rico | VP chips + buildings + shipping | VP pool empty or city full | Role denial, blocking |
| Mission: Red Planet | Area majority on Mars regions | 10 rounds | Role-based sabotage |
| Witch's Brew | Ingredient / potion value | Deck exhaustion | Role nullification |
| Broom Service | Delivery routes + potions | Rounds complete | Brave-contest denial |
| Love Letter | Round wins (tokens) | Tokens threshold | Eliminate players |
| 7 Wonders | Points across categories, weakest category matters | 3 ages | Draft denial |
| Alhambra | Tile value + wall + majority bonuses | Tile pool empty | Buy-out denial |
| Coup | Last player standing | Elimination | Challenge, assassinate, steal |
| Mascarade | Coins, revealed roles score | Coin threshold | Accusations, role swaps |
