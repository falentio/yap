# yap

A research and knowledge archive. Findings live here as durable Markdown.

**Rules for contributors (human or AI): see [AGENTS.md](./AGENTS.md).**

## Layout

| Path | Purpose |
|------|---------|
| [`research/`](./research/) | Written findings — the deliverable, one topic per file |
| [`sources/`](./sources/) | Raw/primary material (articles, papers, docs, datasets) |
| [`notes/`](./notes/) | Fleeting thoughts and an inbox for triage |
| [`archive/`](./archive/) | Superseded material, kept for history |
| [`templates/`](./templates/) | Starting points for new files |

## Research categories

- [technology](./research/technology/README.md) — software, libraries, infra, AI/ML
- [product](./research/product/README.md) — products, vendors, pricing, features
- [business](./research/business/README.md) — companies, markets, strategy
- [science](./research/science/README.md) — papers, academic/technical research
- [howto](./research/howto/README.md) — step-by-step guides
- [reference](./research/reference/README.md) — cheat sheets, glossaries, specs

## Adding research

1. Pick a category from the list above (or propose a new one here first).
2. Copy the matching template from [`templates/`](./templates/).
3. Write the finding, cite every non-obvious claim.
4. Add a link to the category's `README.md` index.
